# BiciRuta Web

Proyecto web de la tienda BiciRuta.

## Estructura
- index.html: pagina principal
- css/estilos.css: estilos de la web
- js/app.js: funcionamiento de la web
- img/: imagenes del proyecto

## Como abrir la web
Abrir index.html con Live Server en VS Code.
Proyecto BiciRuta actualizado con Git y control de versiones.
